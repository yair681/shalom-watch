# אפליקציית שלום לגלקסי ווטש 6

## איך להעלות ל-GitHub ולקבל APK

### שלב 1 — צור חשבון GitHub
- לך ל: https://github.com
- לחץ "Sign up" — חינם

### שלב 2 — צור Repository חדש
- לחץ על "New repository"
- שם: `shalom-watch`
- בחר "Public"
- לחץ "Create repository"

### שלב 3 — העלה את הקבצים
- לחץ "uploading an existing file"
- גרור את כל הקבצים מהתיקייה
- לחץ "Commit changes"

### שלב 4 — קבל APK
- לך ל-Actions (בתפריט העליון)
- חכה שה-build יסתיים (כ-5 דקות) ✅
- לחץ על ה-build → "Artifacts" → הורד את ה-APK

### שלב 5 — התקן על השעון
בדיוק כמו שתרגלנו! 😊
